- **docs(design): Antigravity のロールを既定で有効にする設計** (#4385): `docs/design/agy-role-default-4385.md` を追加。生成物（`~/.gemini/config/agents/<name>/agent.md`）の frontmatter に agy 1.5.8 で確かめた 13 個の `tools`（`swarm` は登録に無く exit 3 になるので入れない）を定数と出典つきで足し、`CM_AGENT_ROLE_ANTIGRAVITY_ENABLED` と `isAgentRoleAdapterEnabled` を消して既定で有効にする方針を決めた。黙ってロールなしで動かないために、起動の前に `agy agent` の一覧と名前を照合し（TUI は未知の名前でも既定の agent で起動するため）、起動の後に TUI の状態の行で名前を確かめて `launched` を記録する（登録に無い道具・起動しない・名前が無いときはセッションを止めて理由を出す）。版の範囲では止めない（exit 3 は agy 自身が止まるので、見えるようにするだけ）。API の `adapterEnabled` は互換のため常に `true` で残す。Antigravity だけ adapter の版を上げ、他の 6 adapter の fingerprint は変えない。不変条件・状態の表・外部呼び出しの失敗の倒れ方・試験の表・未決（推奨つき）・実装の範囲を含む。
