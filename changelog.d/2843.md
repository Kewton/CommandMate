- **feat(detection): 画面が「ダイアログが開いている」と読んだのに hook はターン終了と言っているとき、サーバーログに記録する** (#2843): 画面判定の誤りは、これまで利用者が誤表示に気付くまで分からなかった。承認や質問のダイアログは必ずターンの途中に出るので、画面の判定が `waiting` で hook の最新イベントが `stop` なら、画面の読み違いか、利用者がターン後に開いたメニューのどちらかである。hook がターンの開始と終了を届けるツール（claude・codex・copilot・gemini・opencode）について、これを `approval-after-stop`（承認。ターン終了後には起こり得ないので検出器の誤り）と `menu-after-stop`（選択リスト。仕分けが要る）に分け、セッション・ターン・種類ごとに 1 回、画面の末尾 40 行つきで `[layer-disagreement] layerDisagreement` として記録する。antigravity と Command Code は hook がターンの開始を届けず、途中のダイアログまで誤って記録してしまうため対象外。判定そのものは変えない。
