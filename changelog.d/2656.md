- **feat(ui): サイドバーにエージェント（インスタンス）1 つ＝1 行の「セッション」表示を追加** (#2656): サイドバーの「表示」セレクトに 3 つ目の選択肢「セッション」を追加し、ブランチ単位ではなくエージェント（インスタンス）単位で 1 行ずつ並べるようにした。行は `buildSessionRows()` がブランチの `cliStatus`（roster 全員＋roster 外で稼働中のインスタンス）から作り、ドットはブランチの集約ではなくそのインスタンス自身の状態を出す（終了済みは「アイドル (終了)」）。並びは `sortSessionRows()` が状態（`STATUS_PRIORITY` 昇順＝承認待ちが先）を常に先にし、次に選んだ並び順を使う（並び順が「ステータス」のときだけ、状態の段が向きに従う）。エージェントごとの最終活動時刻は API に無いので「更新日時」はブランチの `updatedAt`。行を押すと `/worktrees/<id>?instance=<instanceId>` へ移動し、詳細画面が roster 到着後に 1 回だけそのインスタンスを選ぶ（PC はヘッダーのインスタンス選択と同じ経路でトークン付きに分割へ配り、スマホは先に表示中へ加えてから選ぶ）。処理後は `router.replace` で `instance` だけを URL から外す（他のクエリは保持）。`ViewMode` は `VIEW_MODES` から導出する形に変え、保存値の検証は `isValidViewMode` に一本化した。`grouped` / `flat` の中身・保存キー・ブランチ行のクリック・既存 testid は変更なし。
