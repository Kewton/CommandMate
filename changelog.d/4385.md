- **docs(design): Antigravity のロールを既定で有効にする設計** (#4385): `docs/design/agy-role-default-4385.md` を追加。生成物（`~/.gemini/config/agents/<name>/agent.md`）の frontmatter に agy 1.5.8 で確かめた 13 個の `tools`（`swarm` は登録に無く exit 3 になるので入れない）を定数と出典つきで足し、`CM_AGENT_ROLE_ANTIGRAVITY_ENABLED` と `isAgentRoleAdapterEnabled` を消して既定で有効にする方針を決めた。黙ってロールなしで動かないために、起動の前に `agy agent` の一覧と名前を照合し（TUI は未知の名前でも既定の agent で起動するため）、照合は新しいプロセスを起こす分岐（再利用の後、ペインの作成の前）だけで行い、再接続は一覧に縛らない。起動後の適用は「起動中／適用を確認済み／明確な不適用／取得不明」で持ち、確認済みかつ入力欄が ready のときだけ本文を送る（画面を取れないことや未描画も送ってよい理由にせず、60 秒の猶予が切れたら未送信の拒否）。不適用・猶予切れでも CommandMate はセッションを自動では止めず、本文を未送信で拒否して理由を見せ、止めるのは人の停止に任せる。拒否は記録の削除（停止の失敗の後を含む）では解除せず、確実に新しく起こした世代が確認を通るまで保つ（サーバーの再起動を越えては保たない）。照合・確認の await の後と本文を入れる境界で世代と状態を照合し直す。PR は送信の門と有効化の 2 本に分ける。版の範囲では止めない（exit 3 は agy 自身が止まるので、見えるようにするだけ）。API の `adapterEnabled` は互換のため常に `true` で残し、CLI の警告は旧いサーバー向けに残す。Antigravity だけ adapter の版を上げ、他の 6 adapter の fingerprint は変えない。不変条件・状態の表・外部呼び出しの失敗の倒れ方・試験の表・未決（推奨つき）・実装の範囲を含む。
