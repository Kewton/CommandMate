- **fix(ui): Files パネルの表示設定メニューで Esc を押すとパネルまで閉じる問題を修正** (#3650): 重ねて開いた Files パネルの中でファイル情報の表示設定メニュー（`FileMetadataToggle`）を開いて Esc を押すと、メニューとパネルが 1 回で両方閉じていた。メニューを開いている間は右クリックメニュー（`ContextMenu`、#3589）と同じく `data-floating-layer="open"` を付け、パネルの Esc / 外側の押下はメニューが閉じるまで待つ（1 回目の Esc でメニューだけ、2 回目でパネルが閉じる）。パネルの document の keydown はメニューより先に登録されるので `preventDefault()` だけでは間に合わないため、印のほうで止める。メニューが閉じる Esc は `preventDefault()` もして、window で受ける下の層（吹き出し、最大化したファイルパネル）にも渡さない。見出しの道具の吹き出し（`Tooltip`）の Esc は今どおり押下を奪わない — フォーカスで即座に出るため、道具をクリックしてパネルを開いた直後はその道具の吹き出しが出ており、そこからの Esc でパネルを閉じる操作が 2 回押しになるのを避ける（理由はコメントに記載）。
