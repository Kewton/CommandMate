- **feat(ui): `/`（Home）のダッシュボードを廃止し、最後に開いたブランチへ移動するようにした** (#2643): `/` はダッシュボード（概要見出し・セッション概要・最近のセッション・ToDo・クイックアクション）を描かず、共有キャッシュ（`useWorktreesCacheContext`）の読込完了後に `router.replace` で行き先を決める。移動先は `localStorage['commandmate.lastOpenedWorktreeId']`（ブランチ画面を開いたときに端末ごとに記録。サーバーには送らない）が**非表示リポジトリを除いた**一覧にあればそのブランチ、無ければ `/sessions`。ポーリングで一覧が更新されても移動は 1 回だけ。初回読込中はスピナー、取得失敗で一覧が空ならエラーと再試行ボタン、取得に成功して一覧が空なら初回ガイド（`OnboardingChecklist`）・「ブランチがありません」・「リポジトリを追加」リンクを出して移動しない（空状態の判定は `repositories` ではなく一覧で行う。`repositories` は `getRepositories` による worktrees の集計なので「未登録」と「登録済み・worktree 0 件」を区別できない）。あわせて `useWorktreesCache` の成功時の `setIsLoading(false)` を一覧と同じ `startTransition` に入れ、「`isLoading=false` かつ一覧が空」のコミットが挟まって `/` がリポジトリ 0 件の画面を一瞬出すのをなくし（失敗時は `catch` で即時）、失敗後に一覧が空のまま再取得している間は `isLoading` を `true` に戻す。ログイン後の移動先・PWA の `start_url`・ヘッダーのロゴはいずれも `/` のままで、この振り分けで行き先が決まる。Home 専用の `HomeHeading` / `HomeQuickActions` / `HomeSessionSummary` / `RecentSessionsList` / `SessionOverviewTile` / `TodoWidget` と、それらだけが使っていた `home.json` のキー（`title` / `running` / `waiting` / `sessionOverview.*` / `sessionSummary.*` / `recentSessions.*` / `todo.*`）を削除した。
