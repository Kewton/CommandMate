- **feat(api,tmux): 検出に依存しない直接入力 API を追加** (#2765): `POST /api/worktrees/[id]/direct-input` を追加。名前付きキー（`Enter` / `Up` / `C-a` …）と文字の列を、検出層にもツール別のキー語彙にも問い合わせずにエージェントの tmux ペインへ順番どおりに届ける。文字は `send-keys -H` で送る（`-l` は末尾の `;` を落とすため）。route は tmux を直接 import せず、CLITool gateway の `sendDirectInput` を通る。
