- **feat(mem): 人が画面で mem の項目を見て、追加・編集・close する（同時編集の競合と古い差分を画面に出す）** (#4227): 新しい画面 `/repositories/:id/mem?branch=<name>[&worktree=<id>]`（Repositories の行の mem の設定の「項目を見る」から開く。PC とスマホで同じ画面）で、ブランチの mode `memWriteFromScreen` の 1 つ（`POST/PATCH /api/worktrees/:id/mem/screen/items[/:itemId[/close]]`、画面の印が無ければ route と service の両方で 403 `screen_only`、CLI に口は無い）で、A の 3 つの入口と同じ検査に加え、人は A の作成者の検査を通るので、書き込みの直前の同じ transaction で作業木・instance の寿命（`isSameInstanceLifetime`、正当な `null → lazy` は通す）・項目の所属のブランチ・要求のブランチ（`expectBranch`、HEAD が別のブランチへ移れば 409 `membership_changed`）・mode
