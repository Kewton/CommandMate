- **ci(e2e): E2E の webServer の heap の上限を 6144MB から 8192MB に上げる** (#4308): playwright が起動する dev サーバー（`npm run dev`）はジョブの `NODE_OPTIONS` を継ぐ。6144MB では約 285 本目付近で heap 約 5.4GB に達して OOM になり、以降の spec が接続拒否で落ちていた（PR #4306・#4310 で各 2 回）。即効の手当てで、どの spec で heap が増えるかの測定は #4308 の残り。unit・integration の上限は変えない。
