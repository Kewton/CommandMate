- **feat(agent-roles): ロールの DB・解決関数・API・生成物の書き込み処理を追加** (#4114): エージェントのロール（Epic #4112）の土台。schema v64 で `agent_roles`（本文は UTF-8 で 16,384 バイトまで、空と空白だけは拒否）、システムの既定、リポジトリの既定、インスタンスの個別指定、起動の記録の 5 テーブルを追加した。`resolveInstanceRole` は個別指定 → リポジトリの既定 → システムの既定 → なし、の順に解決し、上の段の「明示的になし」を下の段で埋めない。`worktrees.repository_path` は最後に scan した root で変わるので所属の答えには使わず、Git common-dir が同じ登録 root をすべて候補にして、設定が食い違えば黙って選ばず「所属が曖昧」を返す。API は `/api/roles`、`/api/settings/agent-role-defaults`、`/api/repositories/[id]/role-defaults`、`/api/worktrees/[id]/instances/roles`。保存状態と effective な結果を別の欄で返し、インスタンスの作成とロールの指定は同じ transaction で確定する。利用中のロールの削除は 409 で参照先を返し、`force` はそれらの行を消すので「なし」に化けず既定を継ぐ。生成物は注入 fingerprint から作る不変の名前で、Codex / Copilot / Antigravity は各 CLI のホーム、ほかはデータディレクトリの下に 0600 で公開し、同じ内容だけを再利用する。違う内容・symlink・権限の緩いファイルは拒否し、書いた後に読み直して形式を検査する。起動処理への配線は #4115 で行うので、この変更だけでは起動の動きは変わらない。
