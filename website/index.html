Level 1

Many agents, one place, in your pocket

  • Every agent on one screen

    Claude Code, Codex, Gemini CLI, Copilot, OpenCode (1.x and V2), Antigravity, Command Code or local models. Every task gets its own session, side by side.

  • A conversation, not a terminal

    Read the agent's reply and answer it like a chat. The raw terminal is still there when you want it.

  • Safely from your phone

    commandmate remote pairs your phone with a QR code, through Tailscale or Cloudflare. Nothing goes on the public internet without your yes.

  • Step away from the desk

    Waiting is read from the agents' own hooks, not guessed from the screen, and reaches your phone as a badge or a push notification.

It runs on the plan you already pay for. CommandMate drives the agent CLIs you are already signed in to. It adds no pay-per-use API bill of its own.

Level 2

Work like a team, not a chat

  • One issue, one workspace

    Each task runs in its own Git worktree: a separate copy of your repository, so two agents never edit the same files under each other.

  • A request you can see

    A task goes out as a contract: the goal, the files it may change, and the checks. It stays in the repository as a file you can read later.

  • Checks decide what's done

    Your own lint, type check and tests run after the work. Their exit code (the number a command ends with) is the verdict, not the agent's summary.

  • The method comes as Skills

    How to plan, hand over and check work is installed from the official Catalog as Skills, and the agent reads it. It is not in someone's head.

Level 3

An AI team that builds and maintains

  • PM, dev lead, workers

    One message to your PM session. It plans the issues, the dev lead hands each one to a worker in its own worktree under a contract, and only what passed the checks becomes a PR. Every step that changes something waits for your approval.

  • Scheduled runs

    Schedules start a session at the times you set, so work can begin while you are asleep, at work or with your family.

The author's daily auto-fix run is the author's own setup, built from scheduled runs and the orchestrate Skill. It shows what these parts can do. It is not a switch in the product.

Set up with your agent

Your agent reads the setup guide and walks you through it, one stage at a time. Each stage is short enough to stop after it and come back later. It asks before it installs anything, and the choices stay yours.

  1. Install and start

    Your agent checks: Node.js, npm, git and tmux are there, and commandmate status reports the server running.

  2. Pair your phone

    Your agent checks: you chose Tailscale or Cloudflare, the phone opened CommandMate, and the pairing code was used.

  3. Add a second agent

    Your agent checks: the new agent is listed for your repository and answered a first small message.

  4. Give your team a PM

    Your agent checks: the orchestrate Skill is installed and the PM replied with a plan, changing nothing yet.

  5. Let checks decide what's done

    Your agent checks: your repository's checks are declared and run once, with an exit code you recognize.

Prefer to do it by hand? It needs macOS / Linux / Windows (WSL2), Node.js v22+, npm, git and tmux; the README has the commands.

Why you can trust it

Runs on your machine

CommandMate runs on your machine. It sends no telemetry, needs no account, and needs no external server to run.

You decide

Approvals come to you. Nothing merges, installs or opens to the internet without your yes. Auto Yes is opt-in, time-boxed, and stops on the patterns you set.

The limits, written down

  • It is a run, not a resident agent. Nothing mutates without an explicit approve.
  • It does not read the code for you. Checks catch what your tests catch.
  • Review by another agent is a step you add, not something the runner does for you.
  • It does not replace tmux, Git worktrees, your terminal, or your agent CLI.
