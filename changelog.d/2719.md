- **chore(lint): lint 対象に tests/ を追加する土台を作る** (#2719): `npm run lint` を `eslint src tests --ext .js,.jsx,.ts,.tsx` に広げ、これまで一度も ESLint がかかっていなかった `tests/` を対象に含めた。あわせて `.eslintrc.json` の `overrides` に `tests/**` エントリを追加し、テストに当てるのが誤りである src 専用ポリシー3つ（i18n 文言直書き検出 #1271 / tmux ゲートウェイ強制 #1922 / Next のページ規約）を恒久的に `off`、実債務6ルール（`no-unused-vars` / `no-explicit-any` / `rules-of-hooks` / `no-require-imports` / `no-this-alias` / `prefer-const`）を段階解消のため一時的に `warn` にした（`npm run lint` は exit 0 のまま）。CI の Lint ジョブから `continue-on-error: true` を外し、lint の結果が実際に PR を止めるようにした。分類は `tests/unit/guards/lint-tests-scope.test.ts` で固定し、`warn` エントリの削除は当該ルールの指摘が `tests/` から実際に消えている場合のみ通るようにした。
