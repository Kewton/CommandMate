- **feat(mobile): スマホのターミナルに、Termux 方式の画面内キーボードによる「直接入力」を追加** (#2799): PC 専用だった #2766 の「直接入力」（検出が読めない画面の最後の出口）をスマホでも使えるようにする。「その他の操作」シートの「セッションを終了」の前に「直接入力」の行（`data-testid="actions-sheet-direct-input"`）を足し、ターミナルタブ・ターミナル面・セッション稼働中の 3 条件がそろうときだけ押せる（満たさないときは `aria-disabled` と理由の短文）。開くと下部バーの composer の位置に `MobileDirectInputKeyboard` を描く — OS のソフトキーボードのイベントは一切読まず、Termux の Extra Keys の既定配列（11 キーを同じ位置に残し、`/`・`-`・`ALT` を ENTER・BS（上スワイプで DEL）・SHIFT に差し替え）の 2 段と、畳める 2 ページの文字の面（英字／数字・記号）で、`DIRECT_INPUT_KEY_VALUES` の 40 個と印字可能 ASCII 95 文字のすべてに届く。CTRL / SHIFT はタップでワンショット、長押しで固定。押したキーはすぐには送らず確認行にチップとして積み（続けて打った文字は 1 件の `text` にまとめ、同じキーの連続は `↓×3` と表示）、`送信 (N)` で 1 リクエストにまとめて送る（Enter は自動で付けない、上限 32 件で満杯の通知）。送信失敗時は「途中まで届いている場合がある」旨を出して列を残し、`OK` か列の編集まで再送信を止める（自動再送しない）。キーは `pointerup` で確定し、押し始めたキーがポインタを捕捉するので指が確認行へ滑っても誤爆しない。積んだ列はメモリだけに置き（localStorage 等に書かない）、インスタンス・タブの切替やセッション停止で閉じて破棄する。モード中は composer を `display:none` で隠して（unmount しないので下書きが残る）ナビゲーションパッド・quick keys・escape hatch を下げ、面切替ピルを押せなくし、プロンプトシートも出さない（#2755 のモード中だけの例外。タブバーのプロンプトバッジは出たまま）。`useDirectInput` に `sendAndWait` / `isSending` を追加（既存の `send` / `error` と PC の `DirectInputBar` は不変）。
