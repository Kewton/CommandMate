- **fix(ui): 送信の再試行で、古い試行の遅い応答（成功・500・409）が新しい行に当たらないようにし、未送信で戻した本文の添付が戻らないことを画面で伝える** (#4417): 楽観表示の送信（`usePendingMessages`）は、応答（成功・500・`unknown`・409・未送信）をその行の最新の試行への応答のときだけ行に当てる。再試行の後に前の試行の応答が遅れて届いても、新しい行の状態・受理の印・送信中の印は変わらない（成功のときは再取得だけ行い、そのエコーが行を確定させる）。破棄した行に遅れて届いた未送信の応答が本文を入力欄へもう一度戻すこともなくなる。未送信（ページの関門・ロールの 409）で本文を入力欄へ戻すとき、添付した画像は入力欄へ戻せない（入力欄の添付はアップロードした File を持つ）ため、「添付した画像は戻せませんでした。もう一度添付してから送ってください」とトーストで伝える（ワークツリー画面の PC・スマホと `/sessions` のタイル）。
