- **feat(opencode-v2): OpenCode V2 の承認（permission）と質問（form）に CommandMate の画面・スマホ・CLI・Auto-Yes から答えられるようにする** (#2945): Epic #2370 Phase 2。SSE の `permission.asked` から承認を差分つきで作り（アクション・対象・`metadata.files[].patch` を承認カードに表示、`Always allow` が保存する `save` も表示）、回答を `POST /api/session/{sessionID}/permission/{requestID}/reply` に `{"decision":"once"|"always"|"reject"}` で送る。`form.created`（実測で form は `data.form` に入る。無いときは `GET /api/session/{id}/form`）から選択肢つきの質問を作り、回答を `POST …/form/{formID}/reply` に `{"answer":{"<key>":<value>}}` で送る（ラベルを選択肢の `value` に戻す。`custom: true` のフィールドだけ自由入力を通す。boolean は Yes/No。選択肢の無いフィールドを含む form は TUI で答える）。`eventIdentity` を `permission-id`（`per_…` / `frm_…`）にし、`listPending` はサーバーの `GET /api/permission/request` と `GET /api/form` を読むので、PC の `PromptPanel`・スマホの `MobilePromptSheet`（承認ボタンと質問の選択肢を新たに描画し、`/respond` に decision id で送る）・`commandmate respond <wt> <番号> --instance opencode-v2`・Auto-Yes（v1 と同じ規則で到着時に `once` を返す。無効時は答えない）がすべて v1 と同じ経路で答えられる。承認ボタンの文言は v2 の TUI に合わせ `Allow once` / `Always allow` / `Reject`（番号と送る値は不変）。質問は v1 と同じく Web Push で通知する。
