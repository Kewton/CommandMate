- **fix(cli): `wait` のポールの取得が返らないと `--timeout` を過ぎても exit 124 にならない問題を修正** (#3974): 通常のポールが呼ぶ 3 つの取得（毎ポールの `current-output`、`promptLedgerStage` と `releaseOrphanTurn` の台帳 messages 読み）に、`--timeout` と `--stall-timeout` の残りの短い方（#3961 の `msBeforeDeadlines`）を上限にした `AbortSignal` を渡す。サーバーが応答しないと次の取得が返るまで `deadlineStage()` に戻らず、期限を過ぎても待ち続けていた。期限による中断は失敗として数えずループの先頭に戻り、`deadlineStage()` が exit 124 で終える。台帳読みの中断も「読めない」へ倒さず期限切れとして同じ出口へ出す（1 往復遅れない）。期限が無ければ signal を渡さず従来どおり、残りが 0 以下なら取得を始めない。期限と関係ない `ApiError`・通信の失敗の扱いと、signal を渡さない呼び出し（`ask` の送信など）は変わらない。共通の手順は `wait-timing.ts` の `readWithinDeadlines()` / `DeadlineReached`。
