- **fix(ui): 画面を移ってもサイドバーとヘッダーが作り直されないようにした** (#2682): サイドバーのナビ（リポジトリ／セッション／レビュー）や歯車の設定を押すと画面全体が作り直され、フルリロードのように見えていた問題を修正。リンクの実装は正しく、原因はシェル（Sidebar / Header / main）を 9 つの `page.tsx` が各自で描いていたこと——page は layout より下にあるため、ルートが変わるたびにシェルごと作り直され、サイドバーのスクロール位置・ホバー中の並び固定・シェルのローカル state が失われていた。新しい `src/components/layout/AppShellGate.tsx` を root layout（`src/app/layout.tsx` の `AppProviders` の内側）に置き、9 つの page から `<AppShell>` を外した。これでシェルは一度だけ mount され、遷移で入れ替わるのは `<main>` の中身だけになる。`/login`・`/offline`・`/proxy`・`/worktrees/<id>/terminal`・`/worktrees/<id>/files/...` は従来どおりシェルなしで、判定は純関数 `shouldRenderShell(pathname)` が持つ（前方一致はセグメント境界で見るため `/loginx` はシェルあり）。ファイルの移動・URL・`AppShell` の中身と props・`useLayoutConfig` の判定・各 page の中身の JSX は変更なし。シェルが root layout の内側に入るのに合わせて `src/app/error.tsx` の `min-h-screen` を `min-h-full` にした（高さの二重取り対策）。シェル自身が投げた例外は、これまでの page 側 error boundary ではなく root の `error.tsx` が拾うようになる。
