- **feat(uat): 専用の OS ユーザーで UAT サーバーを動かす `CM_UAT_ISOLATION=own-home` を足した** (#3312): 毎朝の製品の経路の確認を専用ユーザーで動かすため、その HOME の中に限って codex・claude・antigravity・copilot の hook のファイルを書けるようにした。起動のたびに、実行ユーザーが `CM_UAT_DEDICATED_USER` と一致し、HOME と書き込み先の実体（symlink をたどる）がその HOME の中でそのユーザーの持ち物であることを確かめ、満たさなければ起動を拒否する。準備の失敗での拒否・送り先の固定・`codex exec`/`agy -p` の拒否・CLI の 3000 に落ちない動きは `1` と同じ。`run-server.sh up --own-home` と `.commandmate/uat.yaml` の `own_home` の検査の組を足し、`down` は own-home のとき共有のファイルの変化を記録するが不合格にしない。本番の `agent-event-unresolved-target` のログに `worktreeId` と `cwdHash`（`cwd` の SHA-256 の先頭 16 文字。`cwd` そのものは出さない）を足した。`CM_UAT_ISOLATION=1` と未設定の動きは変わらない。
