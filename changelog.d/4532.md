- **chore(orchestrate): ワーカーの返しの行と、見張りが拾う終わり方をそろえる** (#4532): 契約の goal は手番の最後の行を `DONE: #<N> <sha> verify exit <n>` / `WAIT: <理由>` / `STOP: <理由>` のどれかにし、`IMPL_COMPLETED` は形の外の終わり方（`SHAPE_OUTSIDE`。合格には数えない）にした。`orchestrate-monitor` は、セッションが動いていれば担当（Command Code・claude・codex ほか）を問わず毎ポーリング `capture --pane` を読み、終わり方をその全行で判定する（`capture --json` の `content` / `realtimeSnippet` は窓で、Command Code は上から描くので余白に、codex は分割画面で下端の入力欄だけになるため。`--json` は状態・`promptData` に使う）。許可のプロンプトは、自前の目印の組を持つ担当（claude・Command Code・Antigravity）だけ pane にも目印を当てて拾い、codex などはサーバーの `isPromptWaiting` に任せる。`--pane` の読み取りに失敗したら、失敗が続く間に 1 回 `WARN` を出す（読めたら張り直す）。行は照合の前に 1 つの正規化を通す — ANSI と NBSP、右の差分のパネル（`<文字><空白 2 つ以上>│ …`。claude 2.1.330 で右に「N files edited」が開いていると、行末を固定した読み手が `DONE: … exit 0   │ src/x.ts +12 -3` を拾わなかった）、前後の空白を落とす。行頭の返しの目印を 1 つだけ直後の空白 1 つと一緒に剥がし、1 行だけの返事（実機の `<目印> IMPL_COMPLETED` など）も拾う（入力欄の `❯ DONE: …` や目印が 2 つの行は拾わない）。目印の集合（担当 × プラットフォーム。claude は macOS と Linux・WSL2 で字が違う）は `.claude/skills/orchestrate-monitor/scripts/reply-markers.tsv` の 1 か所に置き、bash と JS はそこからだけ読む（読み手のファイルに目印の字が直書きされていないことも試験で確かめる）。bash（`monitor-lib.sh` の `ml_pane_line`）と JS（`wait-verify.mjs` の `normalizePaneLine` / `returnLineOf`。`hasCompletionSignal` と launch-worker の `endingOfAnswer` も通す）で同じ意味にし、同じ表の行で答えが一致することと、目印のデータから生成した全組み合わせ（ツール × プラットフォーム × 終わり方 × 置き方 × パネルの有無）で本物の見張りと JS の読み手が拾うことを試験で固定した。旧い `IMPL_COMPLETED` の合図の判定も、ほかの読み手と同じ空白（空白・タブだけ）で照合する。
