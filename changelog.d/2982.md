- **feat(opencode-v2): CMATE.md のスケジュールで OpenCode V2 にもモデル・エージェントなどの実行オプションを渡せるようにする** (#2982): CLI Tool 列の `opencode-v2` に v1（#2044）と同じ `--model <provider/model>` / `--agent <name>` / `--variant <name>` / `--continue`（`-c`）/ `--title <text>` を書けるようにした（`TOOLS_WITH_MODEL_SUPPORT` / `TOOLS_WITH_RUN_OPTIONS` に `opencode-v2` を追加）。`opencode2 run` には `--variant` フラグが無い（2.0.18 で `Unrecognized flag`）ため、列の `--variant` は実行時に `-m <provider/model>#<variant>` として渡し、モデル無しの `--variant` は黙って捨てずに構文エラー（行はスキップ、画面・API からの保存も拒否）にする。例: `opencode-v2 --model anthropic/claude-sonnet-4-5 --agent plan` → `opencode2 run --standalone --format json -m anthropic/claude-sonnet-4-5 --agent plan -- <message>`。エラーメッセージの文法は v2 用（`OPENCODE_V2_COLUMN_SYNTAX`）を出し、v1・copilot の文法とエラーメッセージは変えていない。スケジュール編集画面でも OpenCode V2 で Model / Agent / Variant / Title / Continue を入力でき、ja / en の手引きに渡せるオプションを追記した。
