- **feat(worktree): 進み具合（Status）をブランチ行の「…」から変えられるようにし、見出しの select を外した** (#3594): サイドバーの行・タブ列の一覧・パンくずの一覧で共通の「…」（#3576 の `BranchRowActions`）に **Status** を足し、サブメニューで Not set / Ready / In Progress / In Review / Done から選べるようにした（今の値は「Status」の右に出る）。保存は**その行の worktree id** で `PATCH /api/worktrees/<id> { status }` なので、表示中でない worktree も変えられる。選んだ値はすぐ行に出し、保存後は一覧の再取得（`useWorktreesCache` の `refresh`）でサイドバー・タブ列の一覧・パンくずの一覧・Sessions 画面・カードに反映、表示中の worktree なら詳細画面のコントローラが一覧の値の変化を取り込んで Info の欄にもすぐ出す。保存に失敗したら toast（「ステータスを変更できませんでした」）を出して元の値に戻す。行のデータ `SidebarBranchItem` には CLI の `status` とは別のフィールド `worktreeStatus` を足した（混ぜない）。Not set 以外の行には（PC のみ。スマホの引き出しは Status のメニュー以外は従来どおりで札も点も出さない）ブランチ名の右に小さな札（上限 5.5rem・末尾省略）を出し、行の幅が 17rem 未満（既定 224px のサイドバーなど）では同じ色の点に縮めてブランチ名を優先する（文言は title とスクリーンリーダー向けに残す）。PC の見出しの進み具合の select は外し、Info の欄の select は残す。選択肢・札の色・保存関数は `src/lib/worktree-status.ts` にまとめた。同じ worktree の保存は id ごとの順番待ちで直列にし（最後に選んだ値が最後の PATCH になる）、行の「…」・Info の欄・詳細画面の保存はすべてこの経路を通る。進み具合の値は、成功した保存と一覧からの取り込みを 1 本の時計（`worktree-status.ts` の世代番号。保存の成功と取り込みのたびに進む）で「起きた順」に並べ、新しい方だけを使う。保存より前に始まった一覧（`useWorktreesCache`、外部ソースが無いときの `WorktreeSelectionContext` の取得・ポーリング・選択時の詳細取得）や詳細（`useWorktreeDetailController` のポーリング）の取得の応答で、後の保存を戻さない（詳細取得の開始→一覧から In Progress を取り込み→Info で Done を保存→詳細の応答、の順でも Done のまま）。行の「…」で続けて選んだときは最後の選択の保存と再取得が終わるまでその値を出し続け、先の選択の再取得が途中で届いても表示を戻さない。最後の選択は、その保存の後に始まった一覧の取得が成功したこと（`useWorktreesCache` が成功時に記録する取得の世代 `markWorktreeListFetched` / `worktreeListFetchedSince`。`refresh` は失敗しても正常に終わるため戻り値では判定しない）を確かめてから解除し、再取得が失敗したときは保存できた値を出したまま次の成功した取得で解除する。スマホは引き出しの「…」に Status が出る以外は変えていない。
