- **feat(orchestrate): 整合性レビューの相手を `--instance` で選べるようにし、squash のコミットの題名を PR の題名にした** (#3618): `consistency-review.mjs` に `--instance <id>`（既定 `codex`）を追加。capture・ready 待ち・ask・run の記録（agent）・ロック（既定以外は `.lock-<id>`）が同じ値を使うので、Codex の「stream disconnected」のときに `--cli` のラッパーなしで `codex-2` へ切り替えられる。`--instance` を渡さなければ従来と同じ動き。`merge-pr.mjs` は `gh pr merge --squash --subject "<PR タイトル> (#<PR 番号>)"` を渡し（タイトルに `(#<PR 番号>)` が既にあれば二重にしない）、マージ後の develop のコミットの題名が PR の題名と一致する。fold・取り込みがあっても `--pr` 指定でも PR の題名を使う。`--instance` は alias も受け、`instances --json` で実 ID に直す（見つからなければ exit 2）。
