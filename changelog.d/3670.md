- **fix(ui): 2 段目の「…」パネルと最大化したファイルが開いた状態の Esc が、1 回で両方を閉じる問題を修正** (#3670): 「…」パネル（`ActionBarItemsOverflow`）は document の Esc で閉じるが `preventDefault()` しないため（札の理由の document listener が同じ押下で閉じる必要がある、#3660）、window で Esc を受ける最大化の解除（`FilePanelContent`）にも同じ押下が届き、1 回の Esc で 2 層が閉じていた。Esc は前面の層から閉じる。両方とも `<body>` 直下の portal で、最大化したファイル（`fixed inset-0`、`Z_INDEX.MAXIMIZED_EDITOR`=55）が「…」パネル（`Z_INDEX.MODAL`=50）より前面にあるので、パネルは `isCoveredByViewportLayer`（`src/lib/escape-key.ts`、`data-viewport-layer` の層と実際の z-index・文書順を比べる）で背面と分かれば押下に触れず、1 回目で最大化が解除され、見えるようになったパネルが 2 回目で閉じる。パネルが前面にあるときは閉じた押下に印を付け（`markEscapeClosedLayer`、イベントごとの WeakSet）、最大化の解除は `isEscapeNoLayerClosed` で印のある押下を見送る。パネルの z-index は判定のため class の `z-50` から同じ値の inline style に移した。`isUnhandledEscape` の意味は変えていないので、他の受け手（札の理由・アクティビティペイン等）の挙動は不変。
