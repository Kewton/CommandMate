- **feat(sessions): `/sessions` をロールで絞り込めるようにする（タイルの見出しのリンクも該当の instance へ）** (#4389): 「絞り込み」の小画面（PC は Modal、スマホは下のシート）に、ロールのチェックリスト（`GET /api/roles`）と「ロールなし」「判定できない」を追加。判定は `evaluateSessionsFilter` にロールの条件（`roleIds`・`includeNoRole`・`includeAmbiguous`）を足し、instance ごとのロールは `GET /api/sessions/roles`（#4387）を一覧全体で 1 回読む（worktree ごとの roles API は呼ばない）。選んだロールの instance を 1 つでも含む worktree だけが残り、「判定できない」は「ロールなし」と混ぜない。絞っている間は、タイルの instance の切り替えが該当の instance だけになり（最初も該当の先頭、該当が 1 つなら切り替えを出さない、今の instance が外れたら該当の先頭へ）、一覧の行はエージェント表示と `+N` を該当だけで数えて該当した instance のロール名を小さく添え、行のリンクは該当の先頭を `?instance=` に付ける。ロールを読めなかった（`rolesUnavailable` や読み込みの失敗）ときはロールの条件を使わず、小画面と一覧の上に案内を出す（黙って全件や 0 件にしない）。何も選ばなければ表示もリンクも今までどおり。ロールの条件は適用中の条件の数に 1 つとして数える。 絞っている間はタイルの見出しのリンクも、一覧の行と同じ `buildSessionRowHref` で該当の先頭を `?instance=` に付ける（以前はタイルだけ付かず、詳細が前に開いていた instance で開いていた。PC・スマホ共通の `SessionTile`）。絞り込みが無いときのリンクは今までどおり。
