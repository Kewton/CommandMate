- **fix(tmux): 送信の直後の capture が、送信の前に始まった capture の古い画面を受け取る・キャッシュに書き戻す問題を修正** (#3734): `invalidateCache()` は cache だけを消して inflight を残していたため、無効化の後に来た呼び手も無効化の前に始まった fetch に合流して送信前の画面を受け取り、その fetch が #2297 の 250 ms 後の再無効化より遅く返ると送信前の画面が `CACHE_TTL_MS`（5 秒）残っていた。capture cache に世代（session ごと＋全体）を持たせ、`invalidateCache()` は session の世代を進めて該当の inflight も消し、`clearAllCache()` は全体の世代を進める。`getOrFetchCapture()` と `captureSessionOutputFresh()` は始めた時点の世代を控え、await の後に世代が変わっていれば書き戻さない（呼び手自身には結果を返す）。`getOrFetchCapture()` の finally は自分の promise のときだけ inflight を消すので、`clearAllCache()` の後に始まった新しい fetch の singleflight が外れない。無効化が無いときの動き（同時の呼び手が 1 回の fetch を共有し結果をキャッシュする）は変わらない。
