- **feat(auto-yes): Auto-Yes の有効時間を 1〜24 時間から選べるようにする（1h / 3h / 8h はプリセットとして残す）** (#3913): 有効時間を 1〜24 時間の整数時間に広げた。定義は依存の無い新モジュール `src/config/auto-yes-duration.ts` にまとめ（全部の候補 `AUTO_YES_DURATIONS`＝24 値の literal union の型 `AutoYesDuration`、プリセット `PRESET_AUTO_YES_DURATIONS`＝1h / 3h / 8h、CLI の書式 `^(?:[1-9]|1[0-9]|2[0-4])h$`）、`auto-yes-config.ts` と CLI の `duration-constants.ts` は再 export する（CLI の `1h|3h|8h` の写しと旧名 `ALLOWED_DURATIONS` / `DURATION_MAP` / `DURATION_LABELS` は廃止）。API `POST /api/worktrees/:id/auto-yes` は有効化のときだけ 1〜24 時間（3600000 の倍数）を受け付け、範囲外・端数・型違いは 400 で状態も poller も変えない（省略時 1h、無効化は duration を見ないのは従来どおり）。`setAutoYesEnabled` も有効化時に検査し、不正な値は `RangeError` で状態を書き換えない。CLI の `auto-yes --enable --duration` と `send --duration` は `1h`〜`24h`（`0h`・`25h`・`1.5h`・`90m`・`01h`・`+1h`・`1H` などは従来どおり exit 2）、`scripts/orchestrate/launch-worker.mjs` も同じ書式。確認ダイアログは 1h / 3h / 8h のボタンに「その他」（1〜24 時間の select）を足し、**開くたびに 1h に戻す**（ダイアログは常にマウントされていて前回の選択が次の初期値になっていた）。タスク作成ダイアログの select も 1〜24 時間。表示名は ICU（ja `{hours}時間`、en `{hours, plural, one {# hour} other {# hours}}`）。長くすると慎重のモードでも自動で答える許可の確認が増える旨の注記を追加。期限切れ・停止条件・再起動での解除・答え方のモードの安全装置は変えていない。
