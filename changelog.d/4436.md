- **feat(antigravity): Antigravity を無人・エージェント起点で動かす操作を利用形態の申告で判定する共通の方針モジュールを追加** (#4436): Google Antigravity 追加利用規約 6 条（https://antigravity.google/terms ）と FAQ（https://antigravity.google/docs/faq 、2026-11-16 時点）が個人向けプランでの第三者のソフトウェア・エージェント経由の利用を制限しているため、#4436・#4437 が共通に使う判定を `src/lib/tool-policy/` に置いた。`policy.ts`（純粋。型 `CLIToolType` 以外を import せず、DB・fs・node 組み込み・`process.env` を使わないので CLI・画面からも読める）は `decideToolPolicy({ tool, operation, origin, declaration })` を表（データ）で判定する: antigravity 以外と、申告 `api-key` / `enterprise` の antigravity は全部許可、申告 `personal`（既定）の antigravity は `schedule`・`auto-yes` を起点に関係なく、`send`・`ask`・`respond`・`relay` を起点 `legacy`（画面・古い CLI）・`terminal` 以外から拒否し、`code: TOOL_POLICY_DENIED`・`reason: ANTIGRAVITY_CONSUMER_TERMS`・規約と FAQ の `links` を返す。ほかに `parseSendOrigin`（無し → `legacy`、未知の文字列と本文から受けない `relay`・`timer`・`legacy` → `unknown`、文字列でない → `invalid`）、`formatToolPolicyDenial(decision, 'ja' | 'en')`、定数 `RELAY_TOOL_POLICY_DENIED`・`RUN_ORIGIN_ENV`（`CM_RUN_ORIGIN`）・`TOOL_POLICY_DENIED_MESSAGE`。申告の読み出しは `declaration.ts` の `readUsageDeclaration(env)`（`CM_ANTIGRAVITY_USAGE`。前後の空白を除いた小文字の `api-key` / `enterprise` 以外と未設定は `personal`。資格情報は読まない）。CLI の終了コード `ToolPolicyExitCode.DENIED`＝33（方針で断られ何も打たれていない。再送しても同じ）を `src/cli/types/index.ts` に追加し、`.env.example` に `CM_ANTIGRAVITY_USAGE` を追記。この PR では呼び出し側（Schedule・Auto-Yes・送信・relay・CLI・画面）にはつないでおらず、挙動は変わらない。
